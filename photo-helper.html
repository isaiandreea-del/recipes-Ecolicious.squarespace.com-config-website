Ecolicious – Photo helper

Add photos to ingredients/products (small round picture on the clipboard) and recipes (picture on the recipe card). It makes the pictures the right size and writes the lists for you. Everything happens on your computer.

1. Choose your photos

Tip: if a file is named like the thing (Rosii.jpg, 12.jpg, Pizza Margherita.jpg) the helper guesses it for you.

3. (Optional) Keep earlier photos

If you already added photos before, choose your current files so they are kept:

photos.json

ingredient-photos.json

4. Make the files

You get ecolicious-photos.zip. Unzip it, then on GitHub click Add file → Upload files and drag in the photos folder together with photos.json and ingredient-photos.json. Click Commit changes. Wait 1–2 minutes and refresh your site (Ctrl+F5).

GitHub accepts 100 files per upload. If you have more photos, make the ZIP in groups and upload each group (choose the previous JSON files in step 3 each time).
