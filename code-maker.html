Ecolicious – Code maker

Makes one personal Premium code for each customer. The list is saved in codes.json (only scrambled "fingerprints" are stored, so nobody can read the codes from your site). Everything happens on your computer.

1. Open your current list (optional)

If you already made codes, choose your current codes.json so new codes are added to it.

2. Make a new code

Valid until (optional, e.g. one month or one year after payment):

3. Save

Then on GitHub: click Add file → Upload files, drag in the downloaded codes.json (it replaces the old one) and click Commit changes. Changes are live in 1–2 minutes.

How to switch someone off

Press Disable next to the name (or Delete), download the file again and upload it to GitHub. On their next visit Premium turns off. To switch the general code PREMIUM2026 off, delete it from PREMIUM_CODES in index.html.
