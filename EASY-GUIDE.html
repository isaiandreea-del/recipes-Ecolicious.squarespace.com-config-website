Ecolicious – Easy guide

A. Link TikTok and Instagram (when you have the accounts)

  1. Copy your account address. On TikTok it looks like https://www.tiktok.com/@yourname. On Instagram: https://www.instagram.com/yourname. (Open your profile in a browser and copy the address bar.)
  2. Go to your repository on github.com and click the file index.html.
  3. Click the pencil icon (Edit this file), top right of the file.
  4. Press Ctrl+F (Mac: Cmd+F) and search for TIKTOK_URL.
  5. You will see const TIKTOK_URL = "";. Paste your address between the two quote marks: const TIKTOK_URL = "https://www.tiktok.com/@yourname";
  6. Do the same for INSTAGRAM_URL.
  7. Click the green Commit changes… button, then Commit changes again.
  8. Wait 1–2 minutes and refresh your site. The two icons now appear in the top menu and open your accounts. Until you fill in an address, the icon stays hidden.

B. Change the photo of a recipe

Step 1 – Find the recipe number. Open the file RECIPE-NUMBERS.txt from the zip. It lists every recipe with its number (for example "12 - Pizza Margherita"). Write down the numbers of the recipes you have photos for.

Step 2 – Prepare the photo. Save it as .jpg (or .webp / .png), about 800 pixels wide. Name it with the recipe number, for example 12.jpg.

Step 3 – Upload the photo.

  1. On GitHub, open your repository and click Add file → Upload files.
  2. Drag your photos in (up to 100 at a time).
  3. Click Commit changes.

Step 4 – Tell the app which photo belongs to which recipe.

  1. Click the file photos.json, then the pencil icon.
  2. It contains {}. Replace it with one line per photo, like this (recipe number, then file name): 
    {
  "12": "12.jpg",
  "45": "45.jpg",
  "101": "101.jpg"
}
  3. Rules: every line ends with a comma except the last one; use straight quote marks "; the file name must match exactly, including .jpg.
  4. Click Commit changes.

Step 5 – Check. After 1–2 minutes refresh the site (Ctrl+F5). The new photo shows on the recipe card and at the top of the recipe. If you still see the old picture, refresh again or check the file name.

To go back to the watercolor picture: delete that recipe's line from photos.json and commit.
